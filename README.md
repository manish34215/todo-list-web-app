# 📝 Todo List Web App

A beautiful, modern, and fully functional todo list web application built with **HTML**, **CSS**, and **JavaScript**.

## 🚀 Live Demo

**[👉 Click here to use the Todo App](https://manish34215.github.io/todo-list-web-app/)**

Share this link with anyone! No installation needed! 🎉

## ✨ Features

- ✅ **Add Tasks** - Easily add new tasks with the input field
- ✅ **Mark Complete** - Check off completed tasks with a checkbox
- ✅ **Delete Tasks** - Remove individual tasks with the delete button
- ✅ **Filter Tasks** - View All, Active, or Completed tasks only
- ✅ **Task Counter** - See how many tasks are remaining
- ✅ **Clear Completed** - Remove all completed tasks at once
- ✅ **Persistent Storage** - Your tasks are saved locally using localStorage
- ✅ **Responsive Design** - Works perfectly on mobile, tablet, and desktop
- ✅ **Beautiful UI** - Modern gradient design with smooth animations

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling with gradients, animations, and flexbox
- **JavaScript (Vanilla)** - No frameworks, pure JavaScript functionality

## 🎨 Features Breakdown

### Input Section
- Type your task and press Enter or click the "Add" button
- Input validation ensures you don't add empty tasks

### Filtering
- **All** - Shows all tasks
- **Active** - Shows only incomplete tasks
- **Completed** - Shows only completed tasks

### Task Management
- Click the **checkbox** to mark a task as complete/incomplete
- Click **Delete** to remove a task
- Completed tasks show with strikethrough styling

### Data Persistence
- All tasks are automatically saved to browser's localStorage
- Your tasks persist even after closing the browser
- Data is stored locally on your device

## 💾 How LocalStorage Works

Your tasks are saved in your browser's local storage with the key `"todos"`. The app automatically:
- Saves tasks whenever you add, delete, or update one
- Loads saved tasks when you open the page
- Preserves your tasks across browser sessions

## 🎯 How to Use

1. **Open the app** - Open `index.html` in your web browser
2. **Add a task** - Type in the input field and press Enter or click "Add"
3. **Mark complete** - Click the checkbox next to a task
4. **Delete a task** - Click the "Delete" button on the task
5. **Filter tasks** - Click "All", "Active", or "Completed" to filter
6. **Clear completed** - Click "Clear Completed" to remove all done tasks
